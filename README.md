# FANLINK UI

첨부된 FANLINK 화면 디자인을 TypeScript, React Native, Expo SDK 57로 구현한 모바일 UI 프로토타입입니다.

## 실행

Node.js 22 LTS(22.13 이상)와 npm을 준비한 뒤, 압축을 풀고 `package.json`이 있는 폴더에서 실행합니다.

```powershell
npm install
npx expo start
```

- Android 에뮬레이터를 켜고 터미널에서 `a`를 눌러 실행할 수 있습니다.
- 실기기에서는 SDK 57와 호환되는 Expo Go에서 QR 코드를 엽니다. 컴퓨터와 휴대폰은 같은 네트워크에 연결하세요.
- 타입 검사는 `npm run typecheck`로 실행합니다.

## 화면과 동작

- 카카오·네이버 로그인 UI와 홈·커뮤니티·채팅·마이 하단 탭
- 경기 일정, 인기 게시물, 구단·카테고리 필터, 게시글 상세, 좋아요·저장·댓글
- 채팅 목록·검색, 1대1 채팅방, 메시지 입력, 모의 결제·참여 확정
- 내 프로필·계정 및 보안·환경 설정·알림 설정·내 게시글·내 댓글·거래내역
- 공지사항·이용가이드·문의하기 및 빈 탭 레이아웃

로그인 버튼은 홈으로 이동합니다. 댓글·채팅·설정 값은 실행 중에만 보관합니다. 로그인 인증, 실시간 통신, OCR, 결제, 문의 전송을 위한 서버 연결은 포함되지 않습니다. 첨부 이미지에서 제공된 팀 로고·경기장 사진·장식 일부를 사용했으며, 화면 레이아웃과 조작 요소는 React Native 컴포넌트입니다.
